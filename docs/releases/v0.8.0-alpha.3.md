# v0.8.0-alpha.3

This experimental release adds native restriction flow, prescribed-area
histories, and explicit reconstruction of retained reservoir sessions. It also
corrects numerical boundary failures discovered by the independent analytical
review. These are verified additions to the v0.8 and v0.9 foundations; the
general play and certified archive milestones remain open.

## Delivered behavior

- Native `restriction predict` evaluates explicit SI stagnation, back pressure,
  discharge coefficient, and prescribed or compliant area. Native
  `restriction history` integrates up to 256 authored area samples with frozen
  stagnation. Both preserve the Go wire contracts with distinct implementation
  revisions, strict 64 KiB inputs, structured refusals, and full report claims.
- Native `play reconstruct` validates the entire retained transcript before
  numerical work, freshly admits its baseline, and recomputes every costed
  prediction attempt, including refusals. Its exact canonical comparison
  covers every report and receipt. The original summary and complete fresh
  transcript remain available when comparison fails.
- Reconstruction reports baseline admission, prediction work, and retained
  completion separately. Zero-attempt transcripts explicitly report no
  prediction attempts. A matched unfinished session still remains unfinished.
  Rehashed forged numerical values can pass integrity replay and fail
  reconstruction, with the first differing JSON Pointer retained.
- Scaled arithmetic recovers finite sonic temperatures, speeds, mass flow,
  and integrated enthalpy when intermediate values overflow or underflow.
  The choking decision compares actual pressures, preventing a rounded
  pressure ratio from inventing negative outlet thrust. Exact-zero history
  intervals avoid unnecessary heat-capacity work. Unrepresentable positive
  integrated transport is refused rather than reported as exact zero.
- Earlier walk revision 3 evidence remains readable without rewriting it.
  New calculations use revision 4, so reconstruction against a revision 3
  witness reports an explicit implementation-bound mismatch.
- Root and command help, full-precision JSON, six-significant-digit human
  numbers, file/stdin parity, and recovery messages cover the new commands.
  Documentation and the portable agent skill describe the actual native
  command surface and the narrow identity boundary.

## Verification

Required CI builds and tests Go and Rust on Linux, macOS, and Windows. The
source release's `RELEASE-EVIDENCE.json` binds its exact commit to successful
main CI and fresh extracted-source checks. Coverage gates require at least
90 percent aggregate and 80 percent in every Go package and Rust crate.

Local validation used Go 1.27.1 and Rust 1.98.1 on Windows/amd64. Go race
coverage is 94.3 percent (5455/5787 statements). Rust source-line coverage is
97.7 percent (3879/3971 lines): domain 99.6 percent, core 98.4 percent, services
97.2 percent, and CLI 98.6 percent. Every Go package and Rust crate exceeds
the 80 percent floor.

Independent numerical tests include closed-form gamma-three-halves sonic and
subsonic states, a forward-Mach reference grid, constant and triangular area
integrals, small-pressure-gap limits, adjacent choking pressures, and scaled
extremes. Complete Go/Rust comparisons check all JSON structure, metadata,
diagnostics, arrays, and numerical fields under declared arithmetic allowances.
Reconstruction uses a separate exact canonical comparison.

Validation also includes hostile JSON, shape-before-semantics ordering,
duplicate and Unicode handling, reconstruction work counters, rehashed
forgeries, output failures, earlier-release evidence, 22 Go fuzz targets,
20 shuffled Go repetitions, race detection, static analysis, Clippy, rustdoc,
formatting, Markdown and repository checks, and dependency policy gates.

## Compatibility and remaining gates

The request and report schemas retain their experimental `v0alpha1` revisions.
Changed Go numerical implementations are explicitly labeled
`go-oracle.restriction/v0alpha2`, `go-oracle.restriction-history/v0alpha2`,
`go-oracle.walk/v0alpha4`, and `go-oracle.walk-refine/v0alpha2`.
Native restriction and history implementations begin at `v0alpha1`.
No implementation revision is an empirical validation claim.

The new reconstruction schema is
`fart.reservoir-play-reconstruction/v0alpha1` and its comparison profile is
`fart.play.canonical-current-implementation/v0alpha1`. Exact agreement
establishes neither authentication nor identical floating-point results across
platforms. Reconstruction returns evidence without restoring live authority,
inventing a nonce, or assigning a scientific identity.

Native coupled discharge, general play/measurement/knowledge contracts,
checkpoints, branches, certified `.fart` archives, and MCP/A2A services remain
open. Distribution is a source-only prerelease with ZIP and tar.gz archives,
release evidence, and SHA-256 checksums. Signed binaries, attestations, SBOMs,
and reproducible binary builds remain separate release gates.
