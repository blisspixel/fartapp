# v0.8.0-alpha.6

This source pre-release closes the open maintenance issues on top of
v0.8.0-alpha.5. It does not advance a physics, archive, or play milestone.

## Delivered behavior

- `fartapp quickplay 3 --wav out.wav` exits 1 and names both working audio
  commands. Quick Play still does not write a file. `fartapp 3 --wav out.wav`
  writes that level's toy sound. `fartapp walk sonify <case> --output out.wav`
  writes diagnostic sonification of the walk. Successful Quick Play text and
  JSON are unchanged.
- `CLAUDE.md` contains only `@AGENTS.md`. Agent instructions stay in
  `AGENTS.md`.
- Markdownlint CLI 0.50.0 is admitted after review of the nested argparse
  3.0.4 `PSF-2.0` license. That package is development-only documentation
  tooling. SPDX does not mark `PSF-2.0` OSI-approved; the grant is the first
  license in the `Python-2.0` stack already admitted for argparse 2.0.1.
- Documentation overrides pin `minimatch` 11.0.4 and `re2js` 2.8.7 so the
  audit gate clears GHSA-g3hv-75wg-m249 and GHSA-gg6h-894w-4m9c. Upstream
  ranges still select the vulnerable releases.
- A weekly Dependency audit workflow runs `npm audit`, `govulncheck`, and
  `cargo deny check` on `main`. It does not change the required pull-request
  checks.

## Verification and scope

Go and Rust CI runs on Linux, macOS, and Windows. Quality jobs retain lint,
dependency, fuzz, race, parity, and coverage gates. The new audit workflow is
linted with the repository's pinned actionlint and is not a required status
check.

This release publishes source rather than packaged executables. Signed binary
artifacts, SBOMs, and provenance attestations remain release-roadmap work.
The Quick Play refusal adds no acoustic or empirical-validation claim.
