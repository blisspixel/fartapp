# v0.8.0-alpha.2

This experimental release adds bounded native reservoir sessions, inspectable
assurance metadata, and a consistent CLI presentation. It advances the v0.8 and
v0.9 foundations without declaring the general play or certified archive gates
complete.

## Delivered behavior

- Native `play run` processes explicit start, predict, observe, actions, and
  finish commands. Predictions always use the original authored baseline.
  Exact retries retain the original receipt and spend no additional attempt.
  Rejections preserve state; admitted model refusals consume their declared
  attempt and retain the last successful account.
- Text, JSONL, and exact transcript output serve human inspection, command
  adapters, and retained evidence. EOF does not invent a finish. Input,
  command count, work, transcript size, and output have separate bounds.
  Interrupted Unix I/O retries safely; short writes and flush failures stay
  visible.
- `play replay` checks retained structure and RFC 8785/SHA-256 fingerprints
  without executing predictions. Tests distinguish tampering and invalid
  claim metadata from rehashed forged numerical values that integrity alone
  cannot establish as correct.
- `fartapp assurance list|inspect` exposes one embedded registry of 34
  invariant obligations. Repository checks resolve 104 distinct Go test/fuzz
  declarations, validate paths and lifecycle claims, and detect generated
  reference drift. Inspection states that checks were not executed and
  applicability was not evaluated.
- Root and leaf help, bounded recovery messages, and shared six-significant-digit
  human numbers make commands easier to read. Full-precision scientific JSON
  and permanent toy bytes are preserved.
- The portable agent package now exercises 13 Go recipes, including assurance
  metadata. A separate literal eight-command native session is checked through
  the service, CLI, and replay. Current agent-platform research informs
  integration boundaries without adding an agent runtime or model API.

## Verification

Local verification used Go 1.27.1 and Rust 1.98.1 on Windows/amd64. Required
hosted CI independently builds and tests both languages on Linux, macOS, and
Windows. The source release's `RELEASE-EVIDENCE.json` identifies its exact
commit, successful main CI, and fresh extracted-source checks.

Go race coverage is 94.2 percent aggregate (5407/5738 statements), including
99.4 percent in assurance and 97.1 percent in the CLI. Rust source-line
coverage is 97.0 percent (2401/2476 lines), including 96.2 percent in services
and 98.8 percent in the CLI. Every Go package and Rust crate exceeds the
80 percent floor.

Validation includes complete Go/Rust reservoir comparisons, independent
analytical references, hostile command/transcript parsing, idempotency and
revision behavior, read-only observations, no-solver replay, literal native
process tests, 22 Go fuzz targets, and 20 shuffled Go test repetitions.
Formatting, static analysis, rustdoc, Markdown and repository checks, and
dependency advisory/license/source/feature/build-script gates apply.

## Compatibility and remaining gates

The Go and native command sets remain distinct. Native play schemas and
fingerprint profiles are experimental `v0alpha1` contracts. The package version
does not silently revise those schemas or promise stable scientific identity.
Human numerical text is intentionally shorter; use versioned JSON for full
values and stable machine fields.

A local session reference is instance correlation data, not authentication,
nonce freshness, a globally unique case identity, or restore authority.
Retained replay is integrity inspection, not reconstruction, authorship proof,
or empirical validation. General play/measurement/knowledge contracts,
checkpoints, branches, certified `.fart` archives, and MCP/A2A services remain
open. External agent-host installations are not claimed as verified.

Distribution remains source-only, with ZIP and tar.gz archives, an evidence
record, and SHA-256 checksums. Signed binaries, SBOM attestations, platform
notarization, and reproducible binary builds remain separate release gates.
No paid external service was needed.
