# v0.8.0-alpha.7

This source pre-release refines the Quick Play audio refusal from
v0.8.0-alpha.6. It does not advance a physics, archive, or play milestone.

## Delivered behavior

- `fartapp quickplay 3 --wav out.wav` still exits 1 and writes no file. The
  diagnostic names the toy-sound command and the walk sonify command on
  separate lines. A supplied path is quoted in full, up to 4096 bytes. When
  `--wav` has no value, the suggestion uses that intensity's toy name, such
  as `braaap.wav`. A repeated `--wav` is rejected once.
- `fartapp help quickplay` says this command does not write audio and names
  both commands. Its usage line still does not accept `--wav`.
- Successful Quick Play text and JSON are unchanged. `fartapp 3 --wav
  braaap.wav` still writes that level's toy sound. Walk sonify still writes
  diagnostic sonification of the walk, not the toy sound.
- The Dependency audit comment says Dependabot's weekly check is separate
  and does not name a weekday.

## Verification and scope

Go and Rust CI runs on Linux, macOS, and Windows. Quality jobs retain lint,
dependency, fuzz, race, parity, and coverage gates.

This release publishes source rather than packaged executables. Signed binary
artifacts, SBOMs, and provenance attestations remain release-roadmap work.
The refined refusal adds no acoustic or empirical-validation claim.
