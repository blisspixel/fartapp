# v0.8.0-alpha.1

This experimental release adds a native Rust reservoir foundation, estimated
discharge accuracy, and retained software evidence. It advances the v0.8 and
v0.9 work without declaring either complete.

## Delivered behavior

- Four Rust crates separate validated domain inputs, pure calculations,
  stateless services, and native CLI presentation. `fart 1` through `fart 5`
  preserve the permanent toy outputs. `fart reservoir predict` accepts the
  shared authored cases and emits complete typed reports.
- `walk refine` integrates complete discharge under explicit tolerances and
  an evaluation budget. Independent choked, subsonic, and capped-compliance
  references verify its clock. Tolerance satisfaction and discharge completion
  are separate fields.
- `evidence capture` publishes a bounded `.fartevidence` carrier without
  replacing an existing destination. Inspect, verify, and replay preserve the
  retained account; reconstruction explicitly recalculates and reports mismatch.
- Scaled reservoir arithmetic fixes erased finite energy transfers and cooling
  endpoints. Exact powers-of-two tests exposed failures that Go/Rust agreement
  alone did not detect.
- Direct component transfers preserve small declared withdrawals without
  subtracting nearly equal masses. Cross-platform comparisons exposed that
  cancellation; independent reference tests now cover it.
- The Go reservoir parser rejects wrong-case keys and explicit nulls. Missing
  members retain their separate semantic diagnostics.
- Root Go files moved into `cmd/fartapp` and `internal/cli`. Development tools,
  executable fixtures, help evidence, CI, and docs use those entry points.
- Rust 1.98.1, edition 2024, exact minimal dependency features, advisory/license/
  source/build-script gates, and complete-source coverage join the current
  stable Go and documentation toolchains. The portable plugin now tests 12
  actual CLI recipes.

## Verification record

Local verification used Go 1.27.1 and Rust 1.98.1 on Windows/amd64:

- Go tests, race tests, 20 shuffled repetitions, and all 21 fuzz targets passed.
- Go statement coverage was 93.8 percent aggregate; every package exceeded 80
  percent. The CLI reached 96.6 percent and the new carrier 90.3 percent.
- Full Rust tests include native process behavior, independent analytical
  references, complete Go-report comparisons, hostile JSON, and a comparison
  test that detects small-quantity drift and claim substitution.
- Rustfmt, Clippy and rustdoc with warnings denied passed. LLVM line coverage
  was 98.3 percent aggregate and exceeded 97 percent in each crate.
- Repository policy, Markdown links/lint, workflow lint, static analysis,
  Go vulnerability analysis, and Rust advisory/license/source policy passed.

Hosted CI additionally requires both languages on Windows, macOS, and Linux.
The release's `RELEASE-EVIDENCE.json` records the exact source commit, successful
main CI, and fresh extracted-source checks. Local evidence alone does not
authorize promotion. The source archive and evidence file have SHA-256 checksums.

## Compatibility and limits

Go source invocations now use `go run ./cmd/fartapp`. CLI evidence references
point to `go test ./internal/cli`; corresponding exact report fixtures changed
to retain executable references.

The corrected reservoir report declares `go-oracle.reservoir/v0alpha2`.
Dependent walk accounts declare `go-oracle.walk/v0alpha3`, and refinement has
its own `go-oracle.walk-refine/v0alpha1` revision. A witness from an earlier
implementation can honestly mismatch. The provisional reader accepts the
current complete legacy-method witness profile only.

The Rust CLI implements the reservoir subset. `PlayService`, full Go command
parity, certified `.fart` identities, journals, ontology preservation, migrations,
signing, scientific validation, physical audio, and MCP/A2A services remain open.
The carrier's hard-link commit needs filesystem support. Its library supports
cooperative cancellation; abrupt CLI termination can leave a private staging
file. No power-loss durability or cross-platform bit identity is claimed.

Distribution is source-only. Signed binary distribution, SBOMs, attestations,
and reproducible-build comparison are not claimed by this alpha release.
No paid external service was needed for this delivery.
