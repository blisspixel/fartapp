# v0.8.0-alpha.5

This source pre-release fixes the installed CLI's first-run path and zsh
completion. It includes the changes from v0.8.0-alpha.4 and the following fixes.

## Delivered behavior

- Quick Play's three suggested next commands run from an empty working
  directory after installation, without checkout-relative fixtures.
- zsh completion selects top-level commands at the second word and each
  command's operations at the third. It supports both sourcing after `compinit`
  and autoloading `_fartapp` from the completion path.
- The README shows how to add Go and Cargo's default installation directories
  to `PATH`, then verify both binaries with `command -v`.

## Verification and scope

The required Linux CI installs zsh and executes generated completion scripts.
It also follows the README's Go and Rust install recipe on a fresh hosted
runner and checks both command paths and versions. Native zsh Tab checks cover
sourced and autoloaded scripts. Go and Rust CI runs on Linux, macOS, and Windows;
quality jobs retain lint, dependency, fuzz, race, parity, and coverage gates.

This release publishes source rather than packaged executables. Signed binary
artifacts, SBOMs, and provenance attestations remain release-roadmap work.
Diagnostic sonification remains distinct from physical acoustics, and this
release adds no acoustic or empirical-validation claim.
