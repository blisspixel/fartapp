# v0.8.0-alpha.9

Source builds now require Go 1.27.4 or later and include the November
toolchain and standard-library security updates when built with that release.
CI uses the stable Staticcheck 2026.2.2 analyzer. Contributors and CI validate
documentation with Node.js 26.13.1 LTS and npm 12.2.2.

Install the Go CLI with `go install github.com/blisspixel/fartapp/cmd/fartapp@v0.8.0-alpha.9`.
[Go release notes](https://go.dev/doc/devel/release#go1.27.4) ·
[Node release notes](https://nodejs.org/en/blog/release/v26.13.1).
